# ============================================================================
#  requirements.txt: список библиотек Python, которые нужны приложению.
#
#  Это стандартный файл в Python-проектах. Команда
#      pip install -r requirements.txt
#  ставит всё, что здесь перечислено. Строки с # это комментарии.
#
#  Почему у каждой библиотеки указана точная версия через `==`:
#  без версии pip ставит самую новую на момент установки. Сегодня и через
#  год это разные версии, и новая может оказаться несовместимой с нашим
#  кодом. С точной версией любой человек и любая сборка получают один и тот
#  же набор. Обновляют версии осознанно: меняют цифру здесь и проверяют,
#  что всё работает.
# ============================================================================
